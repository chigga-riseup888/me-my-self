## 二、THM 底层硬件保护初始化

```text
sprd_thm_r5p0.c
        │
        ▼
读取 THM IP_VERSION 寄存器
        │
        ▼
实机确认：
THM0 = 0x0500
THM1 = 0x0500
        │
        ▼
按当前机型实际硬件逻辑初始化 THM 阈值
        │
        ├─────────────────────┐
        │                     │
        ▼                     ▼
   75℃ HOT               120℃ OTP
   threshold              threshold
        │                     │
        ▼                     ▼
 THM 硬件高温告警        THM 最底层极限过温保护阈值

```

**说明：**

- 当前机型 THM0 / THM1 实机版本均为 0x0500。
- 120℃ OTP 阈值已由当前 Kernel driver 源码确认。
- 厂商资料将 120℃描述为 Hardware Shutdown；
```text
  当前源码分析已确认 120℃硬件阈值，最终硬件内部断电动作未继续下钻。


```

## 八、AP 极端高温：115℃软件关机

```text

        │

        │
        ▼

        │
        ▼

        │
        ▼

        │
        ▼
THERMAL_TRIP_CRITICAL
        │
        ▼

        │
        ▼

        │

```

**结论：**

```text
115℃ = AP / Linux 软件级过温关机点。


```
